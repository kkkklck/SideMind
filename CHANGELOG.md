# Changelog

## 0.3.3 — Optional detailed explanations

- Add a themed hover card with step-by-step teaching notes and click-to-pin behavior.
- Keep detailed explanations opt-in for new configurations; preserve existing preferences.
- Improve response parsing for echoed labels and longer explanations.
- Support replacing a running instance via local IPC restricted to the current user.
- Render model-supplied card text as plain text rather than HTML.
- Expand regression tests and English documentation.

## 0.3.2 — Initial public source release candidate

- Compact taskbar-anchored settings flyout with custom themed controls.
- Live display preview on the actual taskbar overlay.
- Configurable status, latency, short explanation, font size and width.
- Clipboard image Q&A with configurable vision API presets.
- Local DPAPI-protected credentials, offline demo mode and duplicate filtering.
- Windows GUI and mocked API tests.
