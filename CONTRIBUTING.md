# Contributing to SideMind

Thanks for taking an interest in SideMind!

- For bugs, include the Windows version, Python version, provider/model (not the key), steps to reproduce, and expected and actual behavior.
- For UI changes, describe the interaction and include a screenshot with fictional or redacted data if useful.
- Keep pull requests focused and preserve the lightweight taskbar workflow.
- Add or update tests for changes to behavior.
- Run `py -3.12 -m unittest -v` before opening a pull request.

Please do not share API keys, clipboard contents containing private information, or screenshots of confidential material. Do not submit features intended to bypass exam rules or monitoring.

Contributions are submitted under the project's MIT license.
